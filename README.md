# wonderous-soul-game

Install and run: pip install pygame-ce and python wonderous_soul.py, with the py launcher and macOS/Linux variants.
Controls: a table of every key.
How to play: Soul and Focus, benches, death and shades, doors, and boss gates.
Abilities and upgrades: the cloak, wings and claw, plus what the merchants sell.
Enemies and bosses, then a short troubleshooting section built from the errors we hit (the pygame build failure, "Python was not found", wrong folder).
Credits: it notes the game was made with Claude and isn't affiliated with Team Cherry.
